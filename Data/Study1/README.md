All relevant data for Study 1

*Behavioral data*
* data1.csv is the behavioral data of the animal postcard task
* info1.csv is a processed data file with participant-level information
  
*Simulated data*
* sim_data1.csv is the simulated behavioral data
* sim_info1.csv is a processed data file with simulated participant-level information

*parameter estimates*
* est_020326B.csv estimates of the base version of the model
* est_020326.csv estimates of the local-bias version of the model
* est_060426.csv estimates of the frequency-bias version of the model
* est_050426.csv estimates of the local- and frequency-bias version of the model
