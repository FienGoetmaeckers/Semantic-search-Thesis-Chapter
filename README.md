All relevant data for Study 2

**Behavioral data**
* data2.csv is the behavioral data of the animal postcard task
* info2.csv is a processed data file with participant-level information
  
* data_spat.csv is the behavioral data of the truffle task
* info_spat.csv is a processed data file with participant-level information

* q_info.csv is the questionnaire data

**parameter estimates**
* est_1env_090626.csv estimates of the local-bias version of the model
* est_090626.csv estimates of the local- and frequency-bias version of the model

**processed data**
* info_all is the processed data file containing all relevant participant-level measures for this study
